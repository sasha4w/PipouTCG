# Monorepo PipouTCG — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fusionner `tcg-backend` et `tcg-frontend` dans un monorepo pnpm `PipouTCG` avec historique conservé, un package `@pipou/shared` pour le contrat typé, une CI unique et des déploiements Render/Netlify déclenchés uniquement après succès de la CI.

**Architecture:** `apps/backend` (NestJS, CommonJS), `apps/frontend` (React/Vite, ESM), `packages/shared` (types + constantes, compilé par tsup en CJS+ESM), `packages/tsconfig` (options TS communes). La CI GitHub Actions détecte les zones modifiées, valide, puis appelle le deploy hook Render et `netlify deploy`.

**Tech Stack:** pnpm 12.3.1 (workspaces + catalog), Node 22, TypeScript 5.9, tsup, NestJS 11, TypeORM, React 18, Vite 7, Jest, Vitest, Docker, GitHub Actions, Render, Netlify, MySQL Aiven.

**Spec:** `docs/superpowers/specs/2026-09-23-monorepo-design.md`

## Global Constraints

- Node 22 partout (`.nvmrc`, `engines`, CI, Docker `node:22-alpine`).
- pnpm `12.3.1`, déclaré dans `packageManager` du `package.json` racine.
- Noms de packages : `@pipou/backend`, `@pipou/frontend`, `@pipou/shared`, `@pipou/tsconfig`.
- Le backend est la source de vérité : valeurs d'enums reprises à l'identique, **aucune migration BDD**.
- `@pipou/shared` n'a **aucune dépendance runtime** (ni Nest, ni TypeORM, ni React, ni Zod, ni socket.io).
- Enums partagés = objets `as const` + type homonyme (le front a `erasableSyntaxOnly`, les `enum` TS y sont interdits).
- Style : back en guillemets simples, front et packages en guillemets doubles, `trailingComma: "all"`. Pas de reformatage massif.
- Commande de démarrage backend inchangée : `node dist/main`.
- Aucune action sur la prod (Render, Netlify, GitHub distant) sans accord explicite de l'utilisateur au moment de l'action.
- Chaque commit se termine par :
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  ```

- [ ] **Step 4 : lint restant, back puis front**

Traiter règle par règle, dans l'ordre du nombre d'occurrences :
- `allowDefaultProject` (23, back) : ce sont des fichiers hors du tsconfig vu par `projectService`, sans doute `test/**`.   group: ci-${{ github.ref }}
```yaml
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}

jobs:
  changes:
    runs-on: ubuntu-latest
    outputs:
      backend: ${{ github.event_name == 'workflow_dispatch' || steps.filter.outputs.backend == 'true' }}
      frontend: ${{ github.event_name == 'workflow_dispatch' || steps.filter.outputs.frontend == 'true' }}
    steps:
      - uses: actions/checkout@v4
      - uses: dorny/paths-filter@v3
        if: github.event_name != 'workflow_dispatch'

        with:
          filters: |
            shared: &shared
              - 'packages/**'
              - 'pnpm-lock.yaml'
              - 'pnpm-workspace.yaml'
              - 'package.json'
              - '.nvmrc'
              - '.github/workflows/**'
            backend:
              - *shared
              - 'apps/backend/**'
              - '.dockerignore'

              - *shared

      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4

          node-version-file: .nvmrc
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm --filter @pipou/shared build
      - run: pnpm --filter @pipou/shared test
      - run: pnpm --filter @pipou/backend lint
      - run: pnpm --filter @pipou/backend typecheck
      - run: pnpm --filter @pipou/backend test
      - run: pnpm --filter @pipou/backend build
      - run: docker build -f apps/backend/Dockerfile .

    needs: changes

    services:

        image: mysql:8.4
        env:
          MYSQL_ROOT_PASSWORD: password
          MYSQL_DATABASE: cardcollect
        ports: ['3306:3306']
        options: >-
          --health-cmd "mysqladmin ping -h localhost -ppassword"
          --health-interval 5s --health-timeout 5s --health-retries 20
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version-file: .nvmrc
          cache: pnpm

      - run: pnpm --filter @pipou/backend build

        working-directory: apps/backend

          ENV_FILE=.env.e2e node dist/main > api.log 2>&1 &

            curl -sf http://localhost:3001/health && exit 0
            sleep 2
          done
          cat api.log; exit 1
      - run: pnpm --filter @pipou/backend test:e2e:cucumber
      - if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: e2e-report
          path: |
            apps/backend/reports/
            apps/backend/api.log

  frontend:
    needs: changes
    if: needs.changes.outputs.frontend == 'true'
    runs-on: ubuntu-latest
    env:
      VITE_API_URL: ${{ secrets.VITE_API_URL || 'https://tcg-backend-3lez.onrender.com' }}
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version-file: .nvmrc
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm --filter @pipou/shared build
      - run: pnpm --filter @pipou/frontend lint
      - run: pnpm --filter @pipou/frontend typecheck
      - run: pnpm --filter @pipou/frontend test
      - run: pnpm --filter @pipou/frontend build
      - name: Check bundle size
        working-directory: apps/frontend
        run: |
          SIZE=$(du -sh dist | cut -f1)
          echo "Build size: $SIZE"
          MAX_SIZE=500000
          ACTUAL_SIZE=$(du -s dist | cut -f1)
          if [ "$ACTUAL_SIZE" -gt "$MAX_SIZE" ]; then
            echo "Error: Build size exceeds limit"
            exit 1
          fi
      - uses: actions/upload-artifact@v4
        with:
          name: frontend-dist
          path: apps/frontend/dist/
          include-hidden-files: true
          retention-days: 5

  deploy-backend:
    needs: [changes, backend, e2e]
    if: github.event_name != 'pull_request' && github.ref == 'refs/heads/main' && needs.backend.result == 'success' && needs.e2e.result == 'success'
    runs-on: ubuntu-latest
    steps:
      - name: Trigger Render deploy
        env:
          RENDER_DEPLOY_HOOK_URL: ${{ secrets.RENDER_DEPLOY_HOOK_URL }}
        run: |
          if [ -z "$RENDER_DEPLOY_HOOK_URL" ]; then
            echo "RENDER_DEPLOY_HOOK_URL not set, skipping deploy"
            exit 0
          fi
          curl -fsS -X POST "$RENDER_DEPLOY_HOOK_URL"

  deploy-frontend:
    needs: [changes, frontend]
    if: github.event_name != 'pull_request' && github.ref == 'refs/heads/main' && needs.frontend.result == 'success'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/download-artifact@v4
        with:
          name: frontend-dist
          path: dist
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - name: Deploy to Netlify
        env:
          NETLIFY_AUTH_TOKEN: ${{ secrets.NETLIFY_AUTH_TOKEN }}
          NETLIFY_SITE_ID: ${{ secrets.NETLIFY_SITE_ID }}
        run: |
          if [ -z "$NETLIFY_AUTH_TOKEN" ] || [ -z "$NETLIFY_SITE_ID" ]; then
            echo "Netlify secrets not set, skipping deploy"
            exit 0
          fi
          ls dist/_redirects dist/_headers
          npx --yes netlify-cli deploy --prod --dir dist --site "$NETLIFY_SITE_ID" --auth "$NETLIFY_AUTH_TOKEN"
```
